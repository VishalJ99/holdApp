Hold branding source and app icon reproduction

Source sync:
- Source folder on this MacBook: /Users/vishaljain/hold_branding
- Synced into this repository with:
  `rsync -a --delete --include='Brand Guidelines.pdf' --include='hold_logo_package.zip' --include='Urbanist.zip' --exclude='*' /Users/vishaljain/hold_branding/ app-store-assets/branding/source/`

Source package files:
- source/hold_logo_package.zip contains the logo package and DESIGN.md tokens from Anymark.
- source/Brand Guidelines.pdf contains the visual usage guide.
- source/Urbanist.zip contains the brand font family.

Derived files:
- DESIGN.md is extracted from source/hold_logo_package.zip.
- assets/ contains extracted logo/icon files used for review and App Store page preparation.
- ../../HoldApp/Assets.xcassets/AppIcon.appiconset/ contains regenerated macOS app icon sizes.
- ../../HoldApp-iOS/Assets.xcassets/AppIcon.appiconset/ contains regenerated iOS app icon sizes.
- ../../HoldApp/Assets.xcassets/hold_icon.imageset/hold_icon.png contains the regenerated macOS menu-bar template mark.

Regeneration command:
- `bash app-store-assets/branding/generate_icons.sh`

Validation command:
- `ruby scripts/verify_app_store_assets.rb`

Required tools:
- ImageMagick `magick`
- unzip

Brand choices:
- App icon source: hold_inverse_avatar.png, flattened against brand primary #1F2747 so iOS marketing icons do not contain alpha.
- Menu-bar template source: hold_icon_white.png, resized with transparency preserved for NSImage template rendering.
